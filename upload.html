3發布到網站

發布需要 GitHub 金鑰（只需設定一次，每次發布時貼上）。金鑰只用在這次發布，不會存在網站上。

如何取得 GitHub 金鑰
  1. 用管理者帳號登入 GitHub，開啟 建立 Fine-grained token。
  2. Token name 隨意（例如「地圖上傳」），Expiration 依需要設定。
  3. Resource owner 選 kaohsiung-confined-space-map。
  4. Repository access 選「Only select repositories」，只勾 。
  5. Permissions → Repository permissions → Contents 設為「Read and write」，其他不用動。
  6. 按 Generate token，複製產生的金鑰貼到下方。若 GitHub 顯示需要組織核准，請到組織設定的「Personal access tokens → Pending requests」核准。
